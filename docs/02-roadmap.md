# Product Roadmap: CommunityHub Suggested Answers (FICTIONAL SAMPLE)

> Fictional sample. A Now / Next / Later roadmap avoids false precision: it shows order and intent, not committed dates.

## Now (current focus)

| Theme | Outcome we want | Items |
|---|---|---|
| Foundations | Know what content we can safely rely on | Help-centre content audit; define the "approved source" list |
| Human-in-the-loop | Moderators stay in control | Review screen with approve / edit / reject |

## Next (after Now is validated)

| Theme | Outcome we want | Items |
|---|---|---|
| Retrieval quality | Drafts cite the right article | Tune retrieval; add a "no suggestion" threshold |
| Feedback loop | Learn from moderator edits | Outcome logging; weekly review report |

## Later (not yet committed)

| Theme | Outcome we want | Items |
|---|---|---|
| Coverage | Help more communities | Additional communities and languages |
| Member experience | Faster self-serve | Member-facing "did this help?" prompt |

## Milestones (indicative)

| Milestone | Indicative window | Depends on |
|---|---|---|
| Content audit complete | Q1 (fictional) | Content owner availability |
| Shadow-mode pilot | Q2 | Review screen, retrieval prototype |
| Limited beta | Q3 | Pilot quality review |
| Go / no-go on wider release | Q4 | Beta metrics versus hypotheses |
